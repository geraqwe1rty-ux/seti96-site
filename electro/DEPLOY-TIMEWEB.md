# Развёртывание electro.seti96.ru

Создайте в Timeweb Cloud отдельное приложение из отдельного GitHub-репозитория.

- Окружение: Node.js 22
- Фреймворк: Express
- Установка зависимостей: `npm ci`
- Команда сборки: `npm run build`
- Команда запуска: `npm start`
- Путь проекта: оставить пустым
- Проверка состояния: `/health`

Добавьте в приложение те же секретные переменные, которые используются основным сайтом:

- `LEAD_RELAY_URL`
- `LEAD_RELAY_SECRET`

После успешного деплоя добавьте домен `electro.seti96.ru`. В DNS-зоне `seti96.ru` создайте A-запись с хостом `electro` и IP-адресом, который Timeweb покажет при подключении внешнего домена. После обновления DNS выпустите бесплатный SSL-сертификат.

Счётчик Яндекс Метрики `111934175` уже встроен. Заявки отправляются через общий Google-шлюз в тот же Telegram-чат.
