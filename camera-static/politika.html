2. Обрабатываемые данные

Через форму заявки Оператор может получать имя, номер телефона, адрес объекта, описание задачи, направление обращения, адрес страницы и технические сведения, необходимые для работы и безопасности сайта.

Поля «Адрес объекта» и «Что нужно сделать» заполняются добровольно и не являются обязательными.

3. Цели обработки

Данные используются для обработки обращения, обратного звонка, уточнения задачи, организации осмотра объекта и подготовки расчёта стоимости. Рекламные рассылки без отдельного согласия не осуществляются.

4. Правовое основание

Основанием является согласие пользователя, выраженное установкой обязательного чекбокса перед отправкой формы. При заключении договора дальнейшая обработка необходимых данных может осуществляться для его заключения и исполнения.

5. Порядок и сроки обработки

Обработка включает сбор, запись, временное хранение, уточнение, использование, блокирование, удаление и уничтожение данных автоматизированным или смешанным способом. Доступ предоставляется только уполномоченным лицам.

Если обратная связь состоялась, данные заявки удаляются не позднее одного рабочего дня после завершения обработки обращения. Если связаться с пользователем не удалось, данные удаляются не позднее семи календарных дней. При заключении договора необходимые данные хранятся в сроки, установленные законодательством.

Пользователь вправе получить сведения об обработке данных, потребовать их уточнения, блокирования или уничтожения, а также отозвать согласие. Обращения принимаются по адресу seti-96@yandex.ru.
