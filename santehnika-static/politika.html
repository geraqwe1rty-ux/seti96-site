Политика обработки персональных данных

Оператор обрабатывает имя, номер телефона, адрес объекта и описание проблемы исключительно для связи по заявке и оказания запрошенных услуг.

Обязательными для отправки формы являются имя, телефон и согласие на обработку данных. Адрес и описание проблемы предоставляются по желанию пользователя.

Данные не передаются третьим лицам, кроме случаев, предусмотренных законодательством Российской Федерации, и технических сервисов, необходимых для доставки обращения оператору.
