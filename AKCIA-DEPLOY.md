# Акция «Тепловизор за 800 ₽»

Адрес: https://akcia.seti96.ru. Только этот host обслуживается каталогом akcia-static; сервер не перенаправляет на основной сайт и не меняет остальные поддомены. Предварительные выезды 7–10 ноября 2026: Рассоха, Верхнее Дуброво, Арамиль, Косулино.

Форма обращается из браузера к https://seti96-teplo-akcia.german123312.chatgpt.site/api/booking. Сервер допускает точный Origin https://akcia.seti96.ru, сохраняет заявку в D1 и отправляет существующему боту Сети96. Система очереди и повторных отправок уже настроена; её код хранится в репозитории отдельного Site. Ключи и токены не включены в GitHub. Сбой сети не показывает ложное подтверждение.

Метрика 113687988, после разрешения аналитических cookie. Цели: promo_town_select, promo_lead_start, promo_lead_success, promo_lead_error. Успешная заявка считается после подтверждения записи сервером; контактные данные не передаются в параметры целей. Форма и номер заявки скрыты от Вебвизора.

Исходники страницы: akcia-source. Готовые HTML, CSS и JS: akcia-static. HTML отрисован при сборке, интерактивность подключается через React hydration. Изображение хранится на техническом адресе Site. Для пересборки из каталога akcia-source: npm install && npm run build; затем скопировать outputs/akcia-static в ../akcia-static.

Проверки маршрутизации: node --test tests/akcia.test.mjs. Endpoint /health на akcia.seti96.ru возвращает site: akcia.
