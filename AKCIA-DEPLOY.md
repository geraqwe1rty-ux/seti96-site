# Акция «Тепловизор за 800 ₽»

Адрес: https://akcia.seti96.ru. Только этот host обслуживается каталогом akcia-static; сервер не перенаправляет на основной сайт и не меняет остальные поддомены. Предварительные выезды 7–10 ноября 2026: Рассоха, Верхнее Дуброво, Арамиль, Косулино.

Форма отправляет POST /api/booking на собственный домен. akcia-bookings.mjs проверяет данные, записывает их в DATA_DIR/akcia-bookings.ndjson с fsync и сразу подтверждает сохранение. Telegram отправляется отдельным обработчиком через уже настроенные TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID; ключи остаются только в окружении сервера. Повторная отправка с тем же UUID не создаёт новую заявку. Неудачная доставка повторяется каждые 30 секунд с увеличением интервала до часа; опрос очереди идёт каждые 15 секунд и при запуске сервера.

DATA_DIR должен указывать на постоянный том (как для существующих форм этого сервера). Заявки акции включены в существующий защищённый /api/leads. Ранее принятые заявки в отдельном Site/D1 сохранены без изменений; прежний обработчик и его таймер остаются для старых открытых вкладок. Новая страница не зависит от доступности внешнего домена для отправки формы. При сетевом обрыве клиент делает одну повторную попытку с тем же идентификатором; не подтверждённые сервером заявки не помечаются принятыми.

Метрика 113687988, после разрешения аналитических cookie. Цели: promo_town_select, promo_lead_start, promo_lead_success, promo_lead_error. Успешная заявка считается после подтверждения записи сервером; контактные данные не передаются в параметры целей. Форма и номер заявки скрыты от Вебвизора.

Исходники страницы: akcia-source. Готовые HTML, CSS и JS: akcia-static. HTML отрисован при сборке, интерактивность подключается через React hydration. Изображение хранится на техническом адресе Site. Для пересборки из каталога akcia-source: npm install && npm run build; затем скопировать outputs/akcia-static в ../akcia-static.

Проверки: node --experimental-strip-types --test tests/akcia.test.mjs tests/akcia-bookings.test.mjs tests/akcia-submit.test.mjs. Endpoint /health на akcia.seti96.ru возвращает site: akcia и release: akcia-20261104-booking-v2.
