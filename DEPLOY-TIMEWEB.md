# Развёртывание Сети96 на Timeweb Cloud

## Параметры App Platform

- Окружение: Node.js 22
- Фреймворк: Express
- Конфигурация: 1 CPU, 1 ГБ RAM, 15 ГБ NVMe
- Команда сборки: `npm run build`
- Зависимости: `npm ci`
- Команда запуска: `npm start`
- Путь до директории проекта: оставить пустым
- Путь проверки состояния: `/health`

## Переменные

Добавить в интерфейсе Timeweb значения из `.env.example`. Секреты не загружать в GitHub.

После успешного запуска добавить домены `сети96.рф` и `www.сети96.рф` в настройках приложения и выпустить бесплатный SSL-сертификат.
