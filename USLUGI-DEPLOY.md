# Сайт услуг Сети96

Адрес: https://uslugi.seti96.ru. Статический многостраничный сайт обслуживается существующим Express-приложением Timeweb по имени хоста. Сборка старого сайта и остальные поддомены сохраняют прежний порядок запуска.

## Публикация

1. Включить в развёртывание `uslugi-static/`, `uslugi-leads.mjs` и обновлённый `server.mjs`.
2. Использовать существующие `npm ci`, `npm run build`, `npm start`.
3. Домен uslugi.seti96.ru должен быть привязан к тому же приложению и иметь HTTPS.
4. Форма отправляет заявку в действующий шлюз компании `https://seti96-engineering.german123312.chatgpt.site/api/leads` из браузера — так же, как старые формы. Изолированный файл `prochistka-static/uslugi-relay.html` принимает сообщения только от родительского окна с origin `https://uslugi.seti96.ru`. Существующие файлы сайта прочистки не изменяются. Форма показывает успех только после положительного ответа шлюза. Шлюз сохраняет заявку в своей базе и подтверждает доставку Telegram. Затем форма сохраняет дополнительную локальную запись, явно отмеченную как клиентское подтверждение; локальный сервер не повторяет доставку. Этот маршрут и состав данных подтверждены владельцем. Значения секретов не передаются в браузер.
5. `DATA_DIR` должен указывать на постоянное хранилище. Значение по умолчанию `/tmp/data` не гарантирует сохранность после пересоздания контейнера.

Новые обращения сохраняются в базе действующего шлюза. Дополнительные локальные записи хранятся в `uslugi-leads.ndjson`; в `/api/leads` администратор получает объединённый список. Доступ защищён прежними `ADMIN_USERNAME` / `ADMIN_PASSWORD`. Клиентское подтверждение не считается серверной проверкой. Серверный маршрут отправки сохранён для совместимости, но новая форма не зависит от исходящего соединения Timeweb.

## Проверки

`node --test tests/uslugi.test.mjs` проверяет валидацию, разделение хостов, отказ неподтверждённой доставки, параллельное сохранение и калькулятор. Внешние сообщения из этих тестов не отправляются.

После выкладки проверить главную, каталог, цены, форму, произвольный отсутствующий URL (404), защищённый `/api/leads` (401), а также старые поддомены. Не отправлять клиентские данные в тестах. Полное подтверждение боевой доставки требует согласованного реального обращения либо теста с ответственным сотрудником.

## Контент и аналитика

В каталоге 63 услуги из актуальной матрицы и действующих сайтов. Будущие направления, отсутствующие на работающих сайтах, не представлены как действующие. Цены относятся к работам; оборудование, материалы и выезд указаны отдельно. Исходная таблица с внутренней экономикой в сайт не включена.

Счётчик Яндекс.Метрики: **112564086**. Загружается после разрешения аналитики. События: `lead_start`, `lead_sent`, `phone_click`, `telegram_click`, `email_click`, `estimate_request`. Их нужно выбрать/создать как JavaScript-цели в интерфейсе счётчика. `lead_sent` отправляется только после подтверждения API; клики по телефону не равны состоявшимся звонкам. При отказе от аналитики эти события не собираются.
